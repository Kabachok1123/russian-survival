# Asset licenses

Except for the brown-bear recolor described below, files under
`src/main/resources/assets/russian_survival/textures` and all files under
`src/main/resources/assets/russian_survival/sounds` are original assets created
for Russian Survival and released under CC0-1.0.

- `icon.png`: original AI-assisted pixel-art concept generated for this project,
  then chroma-keyed and resized locally.
- Item, block, armor, and HUD PNG files: original deterministic pixel art created
  for Russian Survival by the project asset generator.
- `textures/entity/brown_bear.png`: color-adjusted from Minecraft's polar-bear
  texture so it remains compatible with the vanilla model. Mojang/Microsoft retain
  all rights to the underlying Minecraft artwork; this file is not offered under
  CC0.
- All OGG files: original procedural synthesis created by the project asset
  generator. They contain no samples, songs, recordings, or third-party audio.

Minecraft is a trademark of Mojang Studios. No Mojang sounds are redistributed.
